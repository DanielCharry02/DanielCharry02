## 🚀 Featured Projects

### 1. SECOP ETL — Public Procurement Data Pipeline

**Python · SQL · PostgreSQL · ETL**

Proyecto personal de ingeniería de datos enfocado en procesar información pública de contratación estatal de Colombia.

**Objetivos y funcionalidades del pipeline:**
- Extraer datos de la fuente de información de SECOP.
- Validar y transformar registros antes de cargarlos.
- Separar registros válidos y rechazados para mejorar la calidad de los datos.
- Conservar información original en una capa cruda para facilitar la trazabilidad.
- Registrar los rechazos en una tabla dedicada.
- Gestionar conflictos durante la carga para evitar duplicados y permitir actualizaciones controladas.

**Estado:** En desarrollo.
